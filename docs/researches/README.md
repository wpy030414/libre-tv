# RESEARCHES — 机制原理研究索引

沉淀**高复杂度**研究（对特定软件的逆向、对私有协议的推敲、长周期实验等）的过程证据：问题、假设、验证手段、结论。结论生效后，正式文档只引用结论，过程留在这里。

## 登记规则
- 准入门槛：问题足够复杂，且需要长期可追溯的证据链。普通排查、一次性复现、随手可查的资料不进本目录。
- **写入前必须取得用户显式同意**：先在对话里提出研究主题与落盘理由，用户明确同意后才新建文件；未获同意不得创建、不得追加。
- 一篇调研一个文件，命名 `NNNN-<kebab-topic>.md`（如 `0001-sqlite-wal-latency.md`）。
- 每篇必须有结论段；无结论的调研标记为「未收敛」，不得据此做决策。
- 结论若改变了系统结构或流程，必须同时新增/更新 `docs/DECISIONS.md` 中的 ADR，并在此处互相引用。
